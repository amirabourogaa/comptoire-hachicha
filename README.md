# Site E-commerce — Développé par Ab-iT

## Présentation du projet

Ce projet est un **site web e-commerce développé par Ab-iT (Amira Bourogaa Information Technology)**.

Le site permet la présentation et la commercialisation de produits en ligne à travers une interface moderne, responsive et adaptée aux besoins du client.

**Développé par :** Ab-iT  
**Site web :** https://abit.tn  
**Type de projet :** Site web e-commerce

---

## Technologies utilisées

Le projet est développé avec :

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
